# Blackpine

Wilderness survival in the browser. Gather, build a claim, and hold your tool cupboard through the raid nights.

Press **Play**, name a claim, then **Wake up**. On a phone, turn it sideways.

## Controls

| Key | Action |
|---|---|
| WASD / Shift | Move / sprint |
| Mouse, E or click | Look, use, gather, fire |
| R / T / Z | Reload / swap ammo / aim |
| V / F | Attachments / light |
| I or Tab | Bag |
| M | Island map (scroll to zoom, double-click to pin) |
| G (Shift+G) | Drop stack (drop one) |
| 1–6 | Hotbar |
| F5 / F9 / Esc | Quick-save / quick-load / pause |

## The basics

- **Start:** you wake with a Rock. Gather wood and stone, then craft a Stone Hatchet and Pickaxe.
- **Progress:** find scrap in barrels, junk, and crates. Research blueprints and build Tier 1 to 3 workbenches to unlock guns, turrets, and explosives.
- **Survive:** raiders hit on raid nights, and three raider camps guard loot chests. Settlers build their own bases, arm up, and fight too.
- **World:** forests, meadows, autumn woods, and scrub, with rivers, bridges, roads, monuments, wildlife, and snow.
- **Difficulty:** Easy, Medium, Hard, or Extreme, set per claim. Higher levels bring bigger raids and tougher raiders.

Full recipes are in [COMPONENTS.md](COMPONENTS.md).
