# Blackpine

Wilderness survival in the browser. Gather, build a claim, and hold the tool cupboard through every tenth night.

## Play

**[Play Blackpine](https://85b9gs5wvy-cmyk.github.io/blackpine/)**

That link opens the same page as [index.html](index.html). The green **Play** button wakes the island. **Continue** picks up a save already stored in this browser.

No install. WASD and the mouse on a computer. On a phone, the stick and a drag to look.
